# Neighbor Farm

Уютная ферма с асинхронным кооперативом. Godot 4.3, GDScript, портрет 720x1280, цель — Yandex Games (Web + Android).

## Запуск
1. Откройте `project.godot` в Godot 4.3 и нажмите F5.
2. Отладочные клавиши: **F10** — перемотать время на +60 с, **F9** — выдать монеты и опыт.
3. Сохранение: `user://save.json`. Удалите файл, чтобы начать заново.

## Экспорт
Web / Android (рендерер GL Compatibility). В пресете экспорта добавьте `data/*.json` в «Фильтры для экспорта не-ресурсных файлов».

Для Яндекс Игр: пресет Web, **Thread Support выключен**, свой HTML-шаблон не нужен — `YandexSdk` сам подгружает `/sdk.js`. В архив для консоли кладутся файлы сборки с `index.html` в корне.

## Яндекс Игры: реклама и покупки
- `autoload/YandexSdk.gd` — мост к JS SDK (только Web): инициализация, `LoadingAPI.ready()` после загрузки сохранения, `GameplayAPI.start/stop` (реклама, окно оплаты, потеря фокуса), `game_api_pause/resume` → звук глушится.
- `AdManager` — полноэкранная реклама при повышении уровня (кроме «Без рекламы»), реклама за награду (награда только по `onRewarded`). `IAP` — каталог, покупка, `consumePurchase` после начисления и сохранения, довыдача необработанных покупок при запуске, восстановление постоянных покупок.
- В Консоли разработчика создайте товары с **ID, совпадающими со `sku` из `data/iap.json`**: `coins_small`, `coins_big`, `speedup_2h`, `no_ads`, `starter_pack` (цена в янах, название и описание на русском и английском, картинка 256×256). Название, описание и цена в магазине берутся из каталога SDK; поле `price` в `iap.json` используется только заглушкой.
- Облачные сохранения: `SaveManager` хранит сохранение и локально, и в данных игрока Яндекса (`player.setData`, лимит 200 КБ и 100 запросов за 5 минут). При запуске игра ждёт облако до `cloud_boot_timeout_seconds` и берёт более свежую копию (по `saved_at`). В облако сохранение уходит раз в `cloud_save_seconds` и сразу — после покупок и при уходе со вкладки. Гость сохраняет прогресс на своём устройстве; кнопка «Войти в Яндекс» в настройках переносит прогресс в аккаунт (если в аккаунте прогресс новее — страница перезагружается с ним).
- Язык игры — только русский: в консоли укажите русский единственным языком. Sticky-баннер не используется.
- Без SDK: в отладочных сборках (редактор, F5) реклама и покупки — заглушки, всегда успешные; в релизных сборках без SDK реклама и покупки отключены.
- Локальная проверка: экспортируйте Web в папку, положите туда `platform/yandex/purchases-catalog.json` и запустите `npx @yandex-games/sdk-dev-proxy -p <папка> --dev-mode=true` — вместо рекламы и оплаты появятся мок-окна SDK. С реальной платформой: `npx @yandex-games/sdk-dev-proxy -p <папка> --app-id=<ID черновика>`; тестовые покупки бесплатны для логинов из «Покупки → Настройки» в консоли.

## Структура
- `autoload/` — Signals, GameState, SaveManager, TimeService, Economy, NeighborAI, IAP (заглушка), AdManager (заглушка), UiFx (анимации интерфейса), Audio (эмбиент, птицы, звуки; глушит звук при сворачивании и рекламе)
- `data/` — весь баланс в JSON. Размер поля по уровням — `config.json` → `field_sizes` (4×4 на старте, 10×10 на 15 уровне), тайминги анимаций — `config.json` → `anim`. Кликер: `crops.json` → `taps` — сколько тапов по растущей грядке выращивают культуру с нуля; возврат за проданное животное — `config.json` → `animal_sell_refund`
- `scenes/` — Main + 5 вкладок, компоненты (Tile, Modal, ContractRow, CurrencyChip; процедурная графика — TileArt, CropArt, IconArt)
- `audio/` — звуки и эмбиент, сгенерированы `tools/make_audio.py` (`python3 tools/make_audio.py`; с модулями `numpy` + `soundfile` эмбиент пишется в OGG). Громкости — `config.json` → `audio`. Переключатели музыки и звуков — внизу вкладки «Магазин».
